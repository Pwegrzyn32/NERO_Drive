# NERO DRIVE – Image Assets

Place the following high-resolution photos in this directory:

| Filename | Description |
|---|---|
| `hero-bg.jpg` | Full-screen hero background – dramatic side or front shot of the Alfa Romeo Giulia in black, ideally at dusk/night |
| `car-side.jpg` | "About The Car" section – clean side-profile shot on a neutral/dark background |
| `gallery-ext-1.jpg` | Gallery – front view |
| `gallery-ext-2.jpg` | Gallery – side profile at sunset |
| `gallery-ext-3.jpg` | Gallery – night driving scene |
| `gallery-wed-1.jpg` | Gallery – wedding arrival at church |
| `gallery-wed-2.jpg` | Gallery – bride and groom with car (wide) |
| `gallery-wed-3.jpg` | Gallery – decorated wedding car |
| `gallery-int-1.jpg` | Gallery – black leather interior |
| `gallery-int-2.jpg` | Gallery – panoramic roof open |
| `gallery-det-1.jpg` | Gallery – red Brembo calipers |
| `gallery-det-2.jpg` | Gallery – Alfa Romeo badge / logo |

## Recommended specs
- Format: JPEG or WebP
- Resolution: minimum 1920×1080 for hero; 1200×900 for gallery
- Color profile: sRGB
- Compression: optimized for web (quality 75–85)

When no image file is found, the website gracefully displays a styled dark placeholder.
